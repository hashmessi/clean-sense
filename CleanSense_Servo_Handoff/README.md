# CleanSense ESP32 Wired Servo Controller

A high-performance, non-blocking USB Serial servo controller running on the **ESP32 DevKit (ESP-WROOM-32)**. Designed to reliably drive a standard micro-servo (**SG90**) or high-torque metal-gear servos (**MG996R**, **DS3218**, or custom models) via USB serial commands from your laptop or PC.

---

## 1. Pinout & Hardware Wiring

| Connection | Wire Color | Connects To | Purpose & Details |
| :--- | :--- | :--- | :--- |
| **Servo Signal** | Yellow / Orange | **ESP32 GPIO13** (labeled `D13`) | 50 Hz PWM control signal generated by ESP32 hardware timer. |
| **Servo Power (+)** | Red | **External 5V–6V Supply (+)** through a switch | External supply capable of delivering **3 A or more** (or 4xAA battery pack). |
| **Servo Ground (-)** | Brown / Black | **External Supply (-)** **AND** **ESP32 GND** | **MANDATORY COMMON GROUND:** Ties external supply reference to ESP32 ground. |
| **ESP32 Power** | USB Cable | **PC / Laptop USB Port** | Supplies clean 5V USB power exclusively to the ESP32 microcontroller. |

```
  +------------------+                    +-----------------------+
  |    ESP32 DevKit  |                    | External 5-6V Supply  |
  |                  |                    | (3A+ / 4xAA Pack)     |
  |           GPIO13 |---- Signal (Yellow)| (+) ----[Switch]----+ |
  |                  |                    | (-) --------------+ | |
  |              GND |----+               +-------------------| |-+
  +------------------+    |                                   | |
                          |                                   | |
                          +----------- Common Ground ---------+ |
                                                              | |
  +------------------+                                        | |
  |   Servo Motor    |                                        | |
  |  (SG90 / MG996R) |                                        | |
  |       Signal (Y) |<---------------------------------------+ |
  |        Power (R) |<-----------------------------------------+
  |       Ground (B) |<---------------------------------------+ (Common Ground)
  +------------------+
```

## 2. Critical Power & Electrical Safety Notes

1. **NEVER power the servo from the ESP32 `3V3` or `5V / VIN` pins!**  
   Servos draw high stall current spikes (up to 800 mA for SG90, 2.5 A+ for MG996R). Running motor current through the ESP32 board will drop the internal voltage rail, cause brownout reset bootloops, or destroy the onboard low-dropout (LDO) regulator.
2. **Common Ground is Mandatory:**  
   The external servo power supply negative terminal (`-`) must be connected directly to an ESP32 `GND` pin. Without a shared common ground reference, the PWM pulse cannot be interpreted by the servo, causing violent jitter, buzzing, or failure to move.
3. **Decoupling Capacitor:**  
   Solder or plug a **470 µF to 1000 µF (16V or higher)** low-ESR electrolytic capacitor directly across the servo positive (Red) and ground (Brown/Black) wires close to the servo. Observe capacitor polarity: long lead with no stripe to `+`, striped side to `-`.
4. **Supply Voltage Sag:**  
   If the ESP32 resets the moment the servo begins moving, your power supply or battery voltage is sagging under the sudden motor load. Upgrade wiring gauge and ensure your external supply provides at least 3 A.

## 3. Windows Setup Instructions

### Prerequisites
1. **USB Data Cable:**  
   Use a micro-USB cable that supports data transfer. Many convenience cables are "power-only / charging" cables without the D+/D- wires.
2. **USB-to-UART Drivers:**  
   Most ESP32 DevKit boards use a Silicon Labs CP2102 or WCH CH340 USB chip.
   * If Windows Device Manager does not show a COM port when the board is plugged in, download and install:
     * [Silicon Labs CP210x Universal Windows Driver](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)
     * [WCH CH340/CH341 Windows Driver](http://www.wch-ic.com/downloads/CH341SER_EXE.html)

### Environment Options
You can use either **VS Code with PlatformIO** or the standalone **Python CLI**:

#### Option A: VS Code (Recommended for Beginners)
1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Open the Extensions tab (`Ctrl + Shift + X`), search for **PlatformIO IDE**, and click **Install**.
3. Go to **File -> Open Folder...** and select this `CleanSense_Servo_Handoff` folder.
4. PlatformIO will automatically detect `platformio.ini` and download the exact pinned toolchain.

#### Option B: Standalone PlatformIO via Python
1. Ensure Python 3.8+ is installed on Windows.
2. Install PlatformIO Core via PowerShell:
   ```powershell
   pip install platformio
   ```

## 4. Build, Upload & Monitor Commands

Open PowerShell in this project folder (`CleanSense_Servo_Handoff`):

### 1. Build Firmware (Compile Only)
```powershell
# Using Python PlatformIO:
python -m platformio run

# Or using plain pio (if on PATH):
pio run
```

### 2. Upload Firmware to ESP32
```powershell
# Using Python PlatformIO:
python -m platformio run -t upload

# Or using plain pio:
pio run -t upload
```

> **BOOT Button Tip:**  
> If the upload stalls at `Connecting........_____.....`, press and hold the **BOOT** (or **IO0**) button on the ESP32 until the flashing progress percentage begins (`Writing at 0x00010000... [10%]`), then release it.

### 3. Open Interactive Serial Monitor (115200 Baud)
```powershell
# Using Python PlatformIO:
python -m platformio device monitor -b 115200

# Or using plain pio:
pio device monitor -b 115200
```
*(To exit the serial monitor, press `Ctrl + C` or `Ctrl + ]`).*

## 5. Serial Command Menu (115200 Baud)

All commands are newline-terminated ASCII strings typed directly into the serial terminal:

| Command | Syntax / Example | Description |
| :--- | :--- | :--- |
| **`s`** | `s` | Print complete system status: active profile, operating mode, current angle, motion state, and safety timers. |
| **`h`** or **`?`** | `h` | Print on-screen help menu and safety instructions. |
| **`home`** | `home` | Move smoothly to home position (`0 deg`). |
| **`a <deg>`** | `a 45` or `a 90` | Smoothly travel to target angle (`0` to `180` deg), clamped to profile safe limits. |
| **`jump <deg>`** | `jump 90` | Instantaneous direct write (maximum raw motor speed, no acceleration ramp). Displays current spike warning. |
| **`sweep`** | `sweep` | Perform a single smooth forward-and-back sweep (`0° -> 90° -> 0°`). |
| **`multi <n>`** | `multi 3` | Perform multi-pass sweep (`1` to `5` consecutive passes). |
| **`profile <name>`** | `profile sg90`<br>`profile mg996r`<br>`profile ds3218`<br>`profile custom` | Switch active servo profile. Automatically configures datasheet pulse envelope (µs), default/max speeds, and travel limits. |
| **`mode <preset>`** | `mode gentle`<br>`mode normal`<br>`mode power` | Set operating speed preset:<br>• **gentle**: 90 deg/s (cold/thick loads)<br>• **normal**: 250 deg/s (fine-tuned standard)<br>• **power**: 500 deg/s (max safe speed with ramp active) |
| **`speed <dps>`** | `speed 200` | Set custom motion speed in degrees per second (`30` to profile max). |
| **`sweepspeed <dps>`** | `sweepspeed 300` | Set dedicated sweep speed in degrees per second. |
| **`ease on|off`** | `ease on` / `ease off` | Enable/disable smoothstep S-curve acceleration & deceleration ramp ($3t^2 - 2t^3$). |
| **`hold on|off`** | `hold on` / `hold off` | Toggle permanent holding torque vs standard settling auto-detach. |
| **`torque hold <ms>`** | `torque hold 2500` (or `hold 2500`) | Hold energized position against mechanical load for specified milliseconds after arrival, then auto-detach to eliminate humming/buzzing. |
| **`range <min> <max>`** | `range 500 2400` | Calibrate PWM pulse envelope in microseconds (`400` to `2600` µs). |
| **`end <deg>`** | `end 120` | Set sweep target turnaround angle (`0` to `180` deg). |
| **`stop`** | `stop` | **Emergency Halt:** Immediately stops motion interpolation and detaches the servo. |

## 6. Safe First Test Order

After uploading the firmware and powering your external servo battery/supply:

1. **`s`** $\rightarrow$ Verify active profile is `sg90`, angle is `0 deg`, state is `IDLE`, and servo is `DETACHED` (0 movement on boot).
2. **`mode gentle`** $\rightarrow$ Engages gentle preset (`90 deg/s`) with acceleration ramp active.
3. **`sweep`** $\rightarrow$ Observe smooth, slow outward/inward sweep (`0° -> 90° -> 0°`).
4. **`mode normal`** $\rightarrow$ Engages standard speed (`250 deg/s`).
5. **`sweep`** $\rightarrow$ Observe crisp, responsive sweep with smooth ease-in and ease-out.
6. **`mode power`** $\rightarrow$ Engages maximum velocity (`500 deg/s`, ramp strictly active).
7. **`sweep`** $\rightarrow$ Observe high-speed clearing pass. Verify ESP32 does not reset.
8. **`torque hold 2000`** $\rightarrow$ Run a move (`a 45`), feel the servo firmly hold position against mechanical load for 2 seconds, then gracefully detach and stop humming.

## 7. Troubleshooting Guide

| Issue | Root Cause | Solution |
| :--- | :--- | :--- |
| **`Could not open COM port`** | USB cable is unplugged, charge-only, or driver missing. | 1. Ensure USB cable supports data.<br>2. Check Windows Device Manager for `CP210x` or `CH340`.<br>3. Run `pio device list` to find port. |
| **Stuck at `Connecting......`** | ESP32 bootloader waiting for serial handshake. | Press and hold the **BOOT** button on the ESP32 until the flashing percentage begins. |
| **Servo vibrates, twitches, or ignores commands** | Missing common ground connection. | Connect external power supply ground (`-`) directly to an ESP32 `GND` pin. |
| **ESP32 reboots when servo starts moving** | Power supply voltage sag / brownout. | 1. Check external supply capacity (must provide 3A+).<br>2. Solder a 1000 µF capacitor across servo power wires.<br>3. Never power servo from ESP32 pins. |
| **`[PROTECTION] DUTY-CYCLE LIMIT REACHED`** | Continuous motion exceeded 60 seconds. | Safety guard activated to prevent motor coil overheating. Wait 15 seconds for cool-down to complete. |
| **`[STALL GUARD] REJECTED 'mode power'`** | More than 3 full-speed sweeps requested in 10s. | Safety guard prevented excessive power-rail stress. Allow 10 seconds of rest before requesting power mode. |
